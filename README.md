# game2

A minimal Phaser 3 starter project. The game concept is intentionally left open for now.

## Requirements

- Node.js 18 or newer

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. The starter displays a simple Phaser scene with a background, title, and interactive placeholder object.

## Project structure

- `index.html` — page entry point
- `src/main.js` — Phaser configuration and placeholder scene
- `src/style.css` — basic page styling

## Next steps

Replace the placeholder scene once the game idea and mechanics are decided.
